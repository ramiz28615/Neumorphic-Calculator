# Wan Studio

Bu klasör Hugging Face video üretim arayüzünü içerir.

- Model: `ramiz282828/NSFW_Wan_1.3b-bucket`
- Text-to-video ve image+text-to-video arayüzü
- Hugging Face Access Token source code'a yazılmaz
- Token yalnızca tarayıcı oturumunda tutulur

> Güvenlik: Daha önce açıkça paylaşılan tokenı iptal edip yeni bir token kullanın.

Açmak için `wan-studio/index.html` dosyasını statik bir sunucuda yayınlayın veya GitHub Pages kullanın.
